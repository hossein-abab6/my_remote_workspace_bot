# Changelog

All notable changes are documented here.

## [0.1.1] - 2026-08-04

### Changed

- Restricted the Telegram main menu to Choose project, Create folder, and Current status
- Moved new-session and permission-mode actions into the selected project's session page
- Removed session shortcuts from the visible Telegram slash-command menu
- Expanded Current status with selected project, active session, last activity, and agent execution state
- Reworked the local dashboard typography, control heights, spacing, switch styling, and responsive form alignment

## [0.1.0] - 2026-08-04

### Added

- Local FastAPI configuration dashboard
- Telegram transport with multiple authorized users
- Safe workspace browser and folder creation
- Project-specific session list and history
- Per-user agent permission mode selection in Telegram
- Claude Code, Codex CLI, Gemini CLI, and custom CLI adapters
- SQLite persistence and Git-safe runtime paths
- Public repository documentation, CI, tests, and setup scripts
