# my_remote_workspace_bot

یک پنل محلی و ربات تلگرام برای اتصال به ایجنت‌های کدنویسی. کاربر از تلگرام پوشه پروژه را انتخاب یا ایجاد می‌کند، سشن جدید می‌سازد، سشن قبلی را ادامه می‌دهد، تاریخچه را می‌بیند و Permission Mode را بدون دست‌کاری کد تغییر می‌دهد.

## امکانات اصلی

- پنل وب برای راه‌اندازی اولیه و ویرایش تنظیمات
- ورود توکن ربات تلگرام و چند User ID مجاز
- محدودکردن دسترسی فایل‌ها به یک مسیر ریشه مشخص
- انتخاب پروژه، ساخت پوشه، مدیریت سشن و مشاهده تاریخچه در تلگرام
- انتخاب مود ایجنت از داخل خود ربات
- Adapter آماده برای Claude Code، Codex CLI، Gemini CLI و CLI سفارشی
- ذخیره تنظیمات، دیتابیس و لاگ‌ها فقط روی سیستم کاربر و خارج از Git
- رابط واکنش‌گرا با ظاهر خنثی و بدون نیاز به Node.js

## راه‌اندازی در ویندوز

```powershell
cd my_remote_workspace_bot
powershell -ExecutionPolicy Bypass -File .\scripts\setup_windows.ps1
.\start_windows.bat
```

پنل در آدرس زیر باز می‌شود:

```text
http://127.0.0.1:8787
```

در پنل:

1. توکن BotFather را وارد کن.
2. یک یا چند Telegram User ID مجاز وارد کن.
3. پوشه ریشه پروژه‌ها را مشخص کن.
4. یک یا چند ایجنت پیکربندی کن. هر ایجنت یک ارائه‌دهنده مجزا دارد و یکی از آن‌ها پیش‌فرض
   است؛ کاربر تلگرام می‌تواند با دستور `/agent` ایجنت دیگری را انتخاب کند.
5. تست مسیر، توکن و ایجنت را اجرا کن.
6. تنظیمات را ذخیره کن تا ربات شروع به کار کند.

اگر ربات بالا نیامد و پنل اعلام کرد که `api.telegram.org` در دسترس نیست، یعنی تلگرام روی
شبکه شما مسدود است. مقدار `MRWB_TELEGRAM_PROXY` را در فایل `.env` روی یک آدرس پروکسی سالم
(`http://…`، `socks5://…` یا `socks5h://…`) تنظیم کن و برنامه را دوباره اجرا کن. متغیرهای
`HTTPS_PROXY` و `ALL_PROXY` هم به‌عنوان جایگزین خوانده می‌شوند.

## ساختار تلگرام

```text
منوی اصلی
├── انتخاب پروژه
│   ├── مرور پوشه‌ها
│   ├── انتخاب پروژه
│   └── نمایش سشن‌های همان پروژه
│       ├── سشن جدید
│       ├── انتخاب سشن قبلی
│       │   ├── بارگذاری پیام‌های قبلی
│       │   ├── ادامه مکالمه
│       │   └── پیام‌های قدیمی‌تر
│       ├── انتخاب ایجنت و مود
│       └── تغییر پروژه
├── ساخت پوشه جدید
│   ├── انتخاب محل
│   ├── دریافت نام پوشه
│   ├── ساخت و انتخاب پوشه
│   └── نمایش صفحه سشن‌های پوشه
└── وضعیت فعلی
    ├── پروژه انتخاب‌شده
    ├── سشن فعال
    ├── زمان آخرین فعالیت
    └── وضعیت اجرای ایجنت
```

گزینه سشن جدید و انتخاب مود در منوی اصلی نمایش داده نمی‌شوند و فقط پس از انتخاب پروژه در صفحه سشن‌های همان پروژه در دسترس هستند.

## نکات امنیتی

- پنل به‌صورت پیش‌فرض فقط روی `127.0.0.1` اجرا می‌شود.
- فایل `data/settings.json` شامل توکن محلی است و در `.gitignore` قرار دارد.
- دیتابیس، لاگ‌ها و کش‌های ایجنت نیز وارد Git نمی‌شوند.
- مودهای `bypassPermissions`، `danger-full-access` و `yolo` پرخطر هستند و فقط باید در محیط قابل اعتماد استفاده شوند.
- قبل از استفاده جدی، پروژه‌های خود را داخل Git نگه دار.

برای جزئیات فنی و توسعه، فایل انگلیسی [README.md](README.md) را مطالعه کن.
